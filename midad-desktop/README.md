# مِداد ستوديو — نسخة سطح المكتب (ويندوز)

التطبيق نفسه (`midad-app.html`) يعمل الآن كبرنامج ويندوز حقيقي عبر **Electron**، دون أي تعديل على الكود الأصلي.

## الهيكل

```
midad-desktop/
├── app/
│   └── index.html      ← التطبيق (نسخة من midad-app.html — حدّثها بعد أي تعديل)
├── main.js             ← الإلكترون: النافذة، القائمة، التنزيلات، التحديث التلقائي
├── preload.js          ← جسر آمن (contextIsolation)
├── package.json        ← الإعدادات، إعدادات المُثبِّت NSIS، ومصدر التحديثات
└── build/              ← ضع هنا icon.ico (اختياري)
```

## التشغيل على ويندوز (للتطوير)

1. ثبّت **Node.js LTS** من https://nodejs.org.
2. داخل مجلد `midad-desktop`:

```bat
npm install
npm start
```

> في وضع التطوير لا يعمل فحص التحديثات (يعمل في النسخة المثبَّتة فقط).

## إنتاج المُثبِّت ‎.exe

```bat
npm run dist
```

الناتج في `release/`:
- `Midad Studio Setup 1.0.0.exe` — المُثبِّت العربي (اختيار مجلد التثبيت، اختصار سطح المكتب وقائمة ابدأ).
- `latest.yml` + `.blockmap` — ملفات التحديث التلقائي (تُنشر مع الإصدار ولا يحتاجها المستخدم).

للبناء المباشر مع النشر إلى GitHub Releases:

```bat
set GH_TOKEN=توكن_جيت_هب
npm run release
```

## التحكم بعناصر صفحة الغلاف

- في القالب الناعم، مرّر المؤشر فوق أي عنصر في الغلاف داخل المحرر لتظهر أدواته: **↑** تحريك لأعلى، **↓** تحريك لأسفل، **✕** إخفاء العنصر.
- العناصر الانسيابية القابلة للترتيب: نوع المستند، العنوان الرئيسي، العنوان الفرعي، الفاصل، بيانات الإعداد.
- عناصر الشعار والختم والتذييل قابلة للإخفاء فقط (مواضعها ثابتة في تصميم الغلاف).
- الإخفاء يُطابق إلغاء التحديد في **تصميم الغلاف ← عناصر الغلاف** — أرجِع أي عنصر من هناك في أي وقت.
- الترتيب الجديد يُحفظ مع المستند ويُطبَّق عند إعادة الفتح، ولا تظهر الأدوات في المعاينة أو الطباعة أو ملف التصدير المستقل.
- القالب التقني لا يتأثر: تخطيطه ثابت بلا أدوات تحكم.

## التحديث التلقائي — كيف يعمل

1. **مرة واحدة**: عدّل في `package.json` القيمتين تحت `build.publish`:
   ```json
   "owner": "اسم_حسابك_على_جيت_هب",
   "repo": "midad-studio"
   ```
   (المستودع يجب أن يكون **عامًّا** أو استخدم `GH_TOKEN` خاصًا للنشر فقط؛ القراءة للمستخدمين من إصدارات المستودع العام.)
2. أصدر النسخة:
   ```bat
   git tag v1.0.3
   git push origin v1.0.3
   ```
   سيبني GitHub Actions المُثبِّت وينشره في **Releases** مع `latest.yml`.
3. التطبيق المثبَّت على جهاز أي مستخدم:
   - يفحص التحديثات **عند الإقلاع** وكل **٤ ساعات**.
   - ينزّل التحديث في الخلفية (مع شريط تقدّم على أيقونة المهمة في ويندوز).
   - يظهر مربع حوار: «إعادة التشغيل الآن» أو «لاحقًا» (يُثبَّت تلقائيًا عند الإغلاق).
   - يمكن الفحص اليدوي من القائمة: **مساعدة ← التحقق من التحديثات**.
   - كل المحاولات والأخطاء تُسجَّل في `%AppData%\midad-studio\updater.log`.

> **مهم**: لا تنسَ رفع `version` في `package.json` قبل كل إصدار — المُحدِّث يقارن الأرقام ويرفض نفس الإصدار.
> التوقيع الرقمي غير مطلوب للتحديث لكنه يمنع تحذير SmartScreen (مرحلة لاحقة).

## الحصول على ‎.exe بدون جهاز ويندوز

1. ارفع المشروع إلى مستودع GitHub.
2. كل دفعة إلى `main` تبني المُثبِّت كأرشيف في **Actions → Artifacts**.
3. دفع وسم `v*` ينشره تلقائيًا في **Releases** (وهذا ما يفعّل التحديث التلقائي للمستخدمين).

## ماذا يضيف الغلاف؟

- نافذة أصلية بحفظ أبعادها وموضعها بين الجلسات.
- قائمة عربية (ملف/تحرير/عرض/مساعدة) مع Ctrl+P للطباعة (يدعم الغلاف الداكن بـ `printBackground`).
- حفظ التصديرات (HTML/JSON) بمربع حوار «حفظ باسم» حقيقي.
- منع فتح تشغيل نسختين معًا.
- عزل أمني كامل (`contextIsolation` + `sandbox`، بدون Node داخل الصفحة).
- تحديث تلقائي كامل عبر GitHub Releases.
- **تخزين آمن**: ملف بيانات في `المستندات\مِداد ستوديو\` + نسخ احتياطية يومية تلقائية.

## بيانات المستخدم — التخزين الآمن

بعد التثبيت، تُحفظ المشاريع والنماذج والأغلفة المستوردة في **ملف بيانات على القرص** بدل اعتمادها على ذاكرة المتصفح:

- مجلد البيانات: `المستندات\مِداد ستوديو\` (افتحه من القائمة: **ملف ← فتح مجلد البيانات**).
- ملف البيانات: `midad-data.json` — يُكتب بطريقة آمنة (ملف مؤقت ثم إعادة تسمية) فلا يتلف عند انقطاع الكهرباء.
- نسخ احتياطية تلقائية يومية في `المستندات\مِداد ستوديو\نسخ احتياطية\` (تُحفظ آخر ١٢ نسخة).
- في متصفح الويب (بدون الغلاف) يبقى الحفظ في `localStorage` كالسابق — الميزات تعمل في الحالين.

## نقل المشاريع إلى جهاز آخر

1. من قائمة التصدير اختر **«نسخة كاملة — كل المشاريع والأغلفة»** → ملف `midad-backup-*.json`.
2. على الجهاز الآخر: **استيراد نسخة** واختر الملف — تُدمَج المشاريع والأغلفة حسب المعرّفات (استبدال المطابق دون حذف الموجود).

## استيراد أغلفة HTML

- من **تصميم الغلاف ← زر الاستيراد** (أو مباشرة من القائمة المنسدلة «الغلاف المستورد»): ارفع ملف غلاف بتنسيق HTML بقياس A4 (794×1123 بكسل).
- يُطبَّع الملف كاملًا: تُحصر أنماطه CSS داخل `.ccv` فقط، وتُزال السكربتات والروابط الخارجية و`@import` و`position:fixed`، ويبقى SVG والوسوم الآمنة.
- يمكن استيراد حتى ٣٠ غلافًا، وحذف أي قالب يعيد مشاريعه تلقائيًا إلى القالب الناعم.

## الخطوط

- **رفع ملف خط**: من الشريط الجانبي «الخطوط المخصصة ← رفع ملف خط» — الصيغ TTF وOTF وWOFF وWOFF2 (حد ٢ م.ب). يُحفظ الخط داخل المشروع ويظهر في خانة «خط المستند» ويُطبَّق فورًا.
- **خطوط ويندوز**: في نسخة سطح المكتب تُقرأ الخطوط المثبّتة على الجهاز تلقائيًا وتظهر في خانة «خط المستند» ضمن مجموعة «خطوط ويندوز المثبّتة» — اختر أي خط وسيُطبَّق على المستند.
- الخطوط المرفوعة تُضمَّن تلقائيًا في ملف HTML المستقل عند التصدير.
- الحذف يعيد المستند إلى خط Cairo تلقائيًا إن كان الخط المحذوف مطبقًا.

## تحديث التطبيق بعد تعديل midad-app.html

```bash
cp midad-app.html midad-desktop/app/index.html
```
