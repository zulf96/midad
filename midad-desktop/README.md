# مِداد ستوديو — نسخة سطح المكتب (ويندوز ولينكس)

التطبيق نفسه (`midad-app.html`) يعمل كبرنامج سطح مكتب حقيقي عبر **Electron** على **ويندوز ١٠/١١** و**أوبنتو ٢٠.٠٤ فأحدث** (وأي توزيعة لينكس حديثة)، دون أي تعديل على كود التطبيق الأصلي.

## الهيكل

```
midad-desktop/
├── app/
│   └── index.html      ← التطبيق (نسخة من midad-app.html — حدّثها بعد أي تعديل)
├── main.js             ← الإلكترون: النافذة، القائمة، التنزيلات، الخطوط، التحديث التلقائي
├── preload.js          ← جسر آمن (contextIsolation)
├── package.json        ← إعدادات المُثبِّت (NSIS لويندوز، AppImage/deb للينكس) ومصدر التحديثات
└── build/
    ├── icon.png        ← أيقونة لينكس (512×512)
    ├── icon.ico        ← أيقونة ويندوز
    └── make-icon.py    ← مولّد الأيقونة من هوية مِداد (Pillow)
```

## التشغيل للتطوير (ويندوز أو لينكس)

1. ثبّت **Node.js 20 LTS** من https://nodejs.org.
2. داخل مجلد `midad-desktop`:

```bash
npm install
npm start
```

> في وضع التطوير لا يعمل فحص التحديثات (يعمل في النسخة المثبَّتة فقط).
> على أوبنتو سطح المكتب لا تحتاج غالبًا أي حزم إضافية؛ إن ظهرت مكتبة ناقصة ثبّت `libgtk-3-0 libnss3 libasound2`.

## إنتاج الحزم

### ويندوز

```bat
npm run dist
```

الناتج في `release/`:
- `Midad Studio Setup 1.2.1.exe` — المُثبِّت العربي (اختيار مجلد التثبيت، اختصار سطح المكتب وقائمة ابدأ).
- `latest.yml` + `.blockmap` — ملفات التحديث التلقائي (تُنشر مع الإصدار ولا يحتاجها المستخدم).

> يتطلب بناء ويندوز تشغيل الأمر على ويندوز أو عبر GitHub Actions؛ لا يُبنى من لينكس إلا بإضافة `wine` (غير متوفر افتراضيًا)، لذا استخدم مسار **الحصول على الحزم بدون جهاز محلي** أدناه.

### لينكس

```bash
npm run dist:linux
```

الناتج في `release/`:
- `Midad-Studio-1.2.1-x86_64.AppImage` — يعمل على معظم التوزيعات دون تثبيت، ويدعم التحديث التلقائي.
- `Midad-Studio-1.2.1-amd64.deb` — حزمة أوبنتو/دبيان (تثبيت نظامي: قائمة التطبيقات + التكامل الكامل).
- `latest-linux.yml` + `.blockmap` — ملفات تحديث AppImage.

> بُني الناتجان محليًا في 2026-11-19 وتحقّقنا من احتواء الحزمة على آخر نسخة من `app/index.html` (إعادة التوزيع التلقائي، أغلفة تتبع المقاس، وبديل إبراز البحث). أعد البناء بعد أي تعديل على `midad-app.html`.

التشغيل والتثبيت:

```bash
chmod +x Midad-Studio-1.2.1-x86_64.AppImage
./Midad-Studio-1.2.1-x86_64.AppImage

# أو حزمة دبيان:
sudo apt install ./Midad-Studio-1.2.1-amd64.deb
```

> **أوبنتو ٢٤.٠٤ فأحدث**: قيود AppArmor على النواة قد تمنع تشغيل ملفات AppImage غير الموثوقة. الحل الموصى به هو تثبيت حزمة **deb**، أو تشغيل AppImage بالخيار `--no-sandbox` عند الحاجة.

## التحديث التلقائي — كيف يعمل

1. **مرة واحدة**: القيم تحت `build.publish` مضبوطة على مستودعك:
   ```json
   "owner": "zulf96",
   "repo": "midad"
   ```
   (المستودع يجب أن يكون **عامًّا** حتى يقرأ التطبيق ملفات التحديث، أو استخدم `GH_TOKEN` للنشر فقط.)
2. أصدر النسخة:
   ```bash
   git tag v1.1.0
   git push origin v1.1.0
   ```
   سيبني GitHub Actions **نسختي ويندوز ولينكس** وينشرهما في **Releases** (مع `latest.yml` و`latest-linux.yml`).
3. في النسخة المثبَّتة:
   - **ويندوز**: تحديث تلقائي كامل عبر `latest.yml`.
   - **لينكس**: التحديث التلقائي يعمل في حزمة **AppImage** فقط عبر `latest-linux.yml`؛ حزمة **deb** تُحدَّث بتنزيل الحزمة الجديدة (قائمة **مساعدة ← التحقق من التحديثات** تفتح صفحة الإصدارات).
   - **فحص خلفي صامت عند الإقلاع** وكل **٤ ساعات** — بلا نوافذ منبثقة: إذا وُجد تحديث يظهر **إشعار داخل التطبيق** بثلاثة خيارات: **«تحديث الآن»** (ينزّل ويُثبّت بعد الموافقة)، **«تجاهل»** (لجلسة العمل الحالية فقط)، **«تذكّرني لاحقًا»** (يُؤجَّل ٢٤ ساعة ويُحفظ). لا يُنزَّل أي شيء قبل ضغط «تحديث الآن».
   - زر **«التحقق من التحديثات»** متاح أيضًا من نافذة «عن مِداد وحقوق المبرمج»، ونتيجته تظهر كإشعار داخل التطبيق.
   - تُسجَّل المحاولات والأخطاء في:
     - ويندوز: `%AppData%\Midad Studio\updater.log`
     - لينكس: `~/.config/Midad Studio/updater.log`

> **مهم**: ارفع `version` في `package.json` قبل كل إصدار — المُحدِّث يقارن الأرقام ويرفض نفس الإصدار.
> التوقيع الرقمي غير مطلوب للتحديث لكنه يمنع تحذير SmartScreen على ويندوز (مرحلة لاحقة).

## الحصول على الحزم بدون جهاز محلي

1. ارفع المشروع إلى مستودع GitHub.
2. كل دفعة إلى `main` تبني حزمتي ويندوز ولينكس كأرشيفات في **Actions → Artifacts**:
   - `midad-windows` (المُثبِّت وملفات التحديث)
   - `midad-linux` (AppImage وdeb وملفات التحديث)
3. دفع وسم `v*` ينشر النسختين معًا في **Releases** (وهذا ما يفعّل التحديث التلقائي).

## ماذا يضيف الغلاف؟

- نافذة أصلية بحفظ أبعادها وموضعها بين الجلسات (ويندوز ولينكس).
- قائمة عربية (ملف/تحرير/عرض/مساعدة) مع Ctrl+P للطباعة (يدعم الغلاف الداكن بـ `printBackground`).
- **حفظ PDF مباشر**: من قائمة التصدير اختر «حفظ PDF» — يُفتح مربع حوار حفظ ويُكتب الملف فورًا (بلا نافذة الطباعة)، مع الاحتفاظ بمقاس A4 والخلفيات الملوّنة. في المتصفح تُفتح نافذة الطباعة كالمعتاد.
- حفظ التصديرات (HTML/JSON) بمربع حوار «حفظ باسم» حقيقي.
- منع فتح تشغيل نسختين معًا.
- عزل أمني كامل (`contextIsolation` + `sandbox`، بدون Node داخل الصفحة).
- تحديث تلقائي عبر GitHub Releases (ويندوز + AppImage).
- **تخزين آمن**: ملف بيانات في مجلد «مِداد ستوديو» داخل المستندات + نسخ احتياطية يومية تلقائية.
- **خطوط النظام**: قراءة خطوط الجهاز المثبّتة تلقائيًا (PowerShell على ويندوز، `fc-list` على لينكس).

## التحكم بعناصر صفحة الغلاف

- في القالب الناعم، مرّر المؤشر فوق أي عنصر في الغلاف داخل المحرر لتظهر أدواته: **↑** تحريك لأعلى، **↓** تحريك لأسفل، **✕** إخفاء العنصر.
- العناصر الانسيابية القابلة للترتيب: نوع المستند، العنوان الرئيسي، العنوان الفرعي، الفاصل، بيانات الإعداد.
- عناصر الشعار والختم والتذييل قابلة للإخفاء فقط (مواضعها ثابتة في تصميم الغلاف).
- الإخفاء يُطابق إلغاء التحديد في **تصميم الغلاف ← عناصر الغلاف** — أرجِع أي عنصر من هناك في أي وقت.
- الترتيب الجديد يُحفظ مع المستند ويُطبَّق عند إعادة الفتح، ولا تظهر الأدوات في المعاينة أو الطباعة أو ملف التصدير المستقل.
- القالب التقني لا يتأثر: تخطيطه ثابت بلا أدوات تحكم.

## بيانات المستخدم — التخزين الآمن

بعد التثبيت، تُحفظ المشاريع والنماذج والأغلفة المستوردة في **ملف بيانات على القرص** بدل اعتمادها على ذاكرة المتصفح:

- مجلد البيانات:
  - ويندوز: `المستندات\مِداد ستوديو\`
  - لينكس: `~/Documents/مِداد ستوديو/`
  - (افتحه من القائمة: **ملف ← فتح مجلد البيانات**).
- ملف البيانات: `midad-data.json` — يُكتب بطريقة آمنة (ملف مؤقت ثم إعادة تسمية) فلا يتلف عند انقطاع الكهرباء.
- نسخ احتياطية تلقائية يومية في `نسخ احتياطية/` داخل المجلد (تُحفظ آخر ١٢ نسخة).
- في متصفح الويب (بدون الغلاف) يبقى الحفظ في `localStorage` كالسابق — الميزات تعمل في الحالين.

## نقل المشاريع إلى جهاز آخر

1. من قائمة التصدير اختر **«نسخة كاملة — كل المشاريع والأغلفة»** → ملف `midad-backup-*.json`.
2. على الجهاز الآخر: **استيراد نسخة** واختر الملف — تُدمَج المشاريع والأغلفة حسب المعرّفات (استبدال المطابق دون حذف الموجود).
3. الملف نفسه يعمل بين ويندوز ولينكس (JSON بترميز UTF-8).

## استيراد أغلفة HTML

- من **تصميم الغلاف ← زر الاستيراد** (أو مباشرة من القائمة المنسدلة «الغلاف المستورد»): ارفع ملف غلاف بتنسيق HTML بقياس A4 (794×1123 بكسل).
- يُطبَّع الملف كاملًا: تُحصر أنماطه CSS داخل `.ccv` فقط، وتُزال السكربتات والروابط الخارجية و`@import` و`position:fixed`، ويبقى SVG والوسوم الآمنة.
- يمكن استيراد حتى ٣٠ غلافًا، وحذف أي قالب يعيد مشاريعه تلقائيًا إلى القالب الناعم.

## واجهة المحرر

- **مظهر شبيه بـ Adobe** (الإصدار ١.١.٠): ترويسة ولوحات مدمجة بألوان محايدة وزوايا حادة وشريط أدوات أيقوني — مألوف لمستخدمي برامج Adobe، ومع ذلك تبقى صفحات المستند بيضاء وبخطوطها وألوانها كما هي تمامًا.
- **وضع ليلي للقوائم فقط** (الإصدار ١.١.٠): زر القمر في ترويسة المكتبة والمحرر يحوّل الترويسات واللوحات والحوارات وشريط الأدوات إلى داكن، **دون لمس صفحات المستند** — الورقة تبقى بيضاء للقراءة والطباعة. يُحفظ الاختيار بين الجلسات.
- **حقوق المبرمج** (الإصدار ١.١.٠): زر «عن مِداد وحقوق المبرمج» في الترويسة، ورابط «حقوق المبرمج» أسفل المكتبة، يفتحان نافذة تعرض الإصدار والمطوّر `zulf96` وحقوق النشر ورابط المشروع — مع زر «التحقق من التحديثات».
- **شريط الإحصاءات العائم** (الإصدار ١.١.٠): عدّادات الكلمات والأقسام والصفحات ودقائق القراءة في شريط صغير أسفل لوحة التحرير (يُخفى في الطباعة والتصدير) بدل شغلها مساحة في اللوحة الجانبية.
- **أزرار الإضافة المختصرة** (الإصدار ١.١.٠): «إضافة قسم» و«إضافة صفحة فارغة» أصبحتا زرَّي علامة (+) مصغّرين مع تلميح عند التمرير — أسرع وأقل تشويشًا.
- **تكبير وتصغير الصفحة** (الإصدار ١.١.٠): مجموعة أزرار (− / النسبة / +) في ترويسة المحرر، من ٥٠٪ إلى ٢٠٠٪ بخطوة ١٠٪؛ انقر على النسبة (مثل «١٥٠٪») للعودة إلى الحجم الأصلي فورًا. يُحفظ التكبير للتطبيق كله ولا يؤثر إطلاقًا في الطباعة أو تصدير PDF أو المعاينة.
- **لون هوية مخصص (RGB)** (الإصدار ١.١.٠): مربع ألوان بجوار العيّنات الجاهزة في «لون الهوية» — اختر أي لون بالضبط، وتتولد تلقائيًا درجات النص والخلفية الفاتحة المناسبة له.
- **إخفاء شعار مِداد واسمه من الغلاف** (الإصدار ١.١.٠): مفتاح «شعار مِداد واسمه في الغلاف» بجوار اسم المؤلف يزيل (أو يعيد) شارة «مِداد STUDIO» وشعار «مِداد» معًا من الغلاف — ويمكن أيضًا التحكم بكلٍّ منهما على حدة من «تصميم الغلاف ← عناصر الغلاف».
- **ترتيب ترويسة المحرر** (الإصدار ١.١.٠): أزرار العمل على المستند أولًا (لوحة المستند ← التكبير ← المعاينة ← التصدير ← الطباعة) ثم فاصل، وبعده أزرار التطبيق (الوضع الليلي ← الحقوق) في الطرف الآخر — فلا تختلط أوامر المستند بأوامر الواجهة. تتقلّص الأزرار إلى ٣٢ بكسل ويختفي زر الحقوق على الشاشات الصغيرة مع تمرير أفقي للترويسة بدل الفوضى.
- **إعادة تنظيم شريط التنسيق** (الإصدار ١.١.٠): صفّان متوازنان — الأول لأدوات النص والفقرة (تراجع/إعادة، عريض/مائل/تسطير/شطب، عناوين وقوائم واقتباس، محاذاة وإزاحة واتجاه وأس مرتفع/منخفض)، والثاني للألوان وحجم الخط ونوعه وتباعده وأدوات الإدراج العشر — فلم يعد الصف الأول شبه فارغ ولا الثاني مزدحمًا.
- **إصلاحات الوضع الليلي** (الإصدار ١.١.٠): توحيد أسطح الحقول والقوائم والنوافذ المنبثقة والبطاقات والشرائح والشارات والأشرطة العائمة على درجات داكنة ثابتة، وضبط `color-scheme` ليطابق أشرطة التمرير الأصلية، وإصلاح أرقام الفهرس وخلفيات العدّادات ومفتاح التبديل (أزرق Adobe بدل الأخضر) — مع بقاء صفحات المستند بيضاء تمامًا.
- **تقسيم تلقائي عند امتلاء الصفحة** (الإصدار ١.١.٠): أثناء الكتابة أو اللصق، إذا تجاوز المحتوى سعة الورقة يُنشئ البرنامج صفحة تكملة جديدة تلقائيًا وينقل إليها الزائد عند أقرب حدّ فقرة (أو أقرب كلمة داخل فقرة طويلة)، ثم يضع المؤشر في بدايتها لإكمال الكتابة مباشرة. ينشئ عدة صفحات دفعة واحدة عند الحاجة، ويحافظ على مقاس الصفحة المختار وترقيم الصفحات الفعلي في شريط الإحصاءات والفهرس — دون أن تُحتسب صفحات التكملة كأقسام جديدة.
- **اختفاء النص التمهيدي عند الكتابة** (الإصدار ١.١.٠): عبارة «ابدأ الكتابة هنا…» تظهر كتلميح خفيف في الورقة الفارغة وتختفي فور أول حرف تُكتبه؛ وفي المستندات القديمة التي كانت تحتويها كنص حقيقي يُزال النص تلقائيًا عند أول تحرير مع الإبقاء على ما كتبته بعده.
- **مقاس الصفحة واتجاهها** (الإصدار ١.١.٠): اختر عند إنشاء المستند (A4، A5، Letter، Legal، B5) مع الاتجاه العمودي أو الأفقي، ويمكن تغييرهما لاحقًا من «إعدادات المستند ← مقاس الصفحة / اتجاه الصفحة». يتغيّر عرض الورقة وارتفاعها في المحرر والمعاينة، ويُضبط `@page` تلقائيًا عند الطباعة وتصدير PDF، كما يُحفظ الاختيار مع المستند ويظهر في شريط الإحصاءات.
- **بحث داخل المستند** (الإصدار ١.١.٠): زر العدسة في ترويسة المحرر أو `Ctrl+F` / `Cmd+F` يفتح شريط بحث يبحث في كل صفحات المستند ويُبرز جميع التطابقات (الأصلي بلون والحالي بلون مختلف) مع عدّاد ونتائج سابقة/تالية ENTER / Shift+ENTER وانتقال تلقائي إلى النتيجة. لا تُحفظ علامات التمييز داخل المستند، وفي المتصفحات التي لا تدعم CSS Highlight يُستخدم بديل محلي بنفس النتيجة.
- **إعادة توزيع فورية عند تغيير المقاس أو الاتجاه** (الإصدار ١.١.٠): بمجرد تبديل «مقاس الصفحة» أو «اتجاه الصفحة» من لوحة الإعدادات يُعيد البرنامج تقسيم كل الصفحات الحالية لتتناسب مع المقاس الجديد، مع الحفاظ على النص وعدّادات الصفحات.
- **الأغلفة المستوردة تتبع مقاس الصفحة** (الإصدار ١.١.٠): الغلاف HTML المرفوع يُقاس بمقياس موحّد (`min(عرض/794, ارتفاع/1123)`) ليتمركز داخل الورقة الجديدة بدل بقائه مثبّتًا على A4.

## إطار الصفحة المتدرج

- نوع الإطار «متدرج» يرسم حلقة تدرّج لونية حول الصفحة كـ `border-image` — يبقى المحتوى ظاهرًا بالكامل في المحرر والمعاينة والطباعة وملف PDF (كانت النسخ القديمة تغطّيه بطبقة بيضاء، ثم تبيّن أن تقنية القناع تُتجاهَل في مسار الطباعة فاستُبدلت بالحدود المتدرجة في هذا الإصدار).
- **تدرّج لوني في كل الأطواق** (الإصدار ١.١.٠): مفتاح «تدرّج لوني للإطار» يلوّن جميع الأطواق (رفيع، مزدوج، متقطع، زوايا، كلاسيكي، زخرفي، ظل، موجات، شبكة) بتدرّج بين لون الإطار ولون النص، ويطبع معها دون «خلفيات الرسومات». إطفاؤه يعيد الألوان الصلبة.
- **هوامش مخصّصة بالاتجاهات الأربعة** (الإصدار ١.١.٠): حقول أعلى/أيمن/أسفل/أيسر بالملّيمترات، مع خيار «مخصّصة» في قائمة الهوامش وزر **«حذف الهوامش»** يصفّرها (محتوى بكامل عرض الورقة). تُطبَّق في المحرر والطباعة والتصدير معًا وتُحفظ مع المستند.

## الخطوط

- **رفع ملف خط**: من الشريط الجانبي «الخطوط المخصصة ← رفع ملف خط» — الصيغ TTF وOTF وWOFF وWOFF2 (حد ٢ م.ب). يُحفظ الخط داخل المشروع ويظهر في خانة «خط المستند» ويُطبَّق فورًا.
- **خطوط النظام**: في نسخة سطح المكتب تُقرأ الخطوط المثبّتة على الجهاز تلقائيًا (ويندوز: PowerShell، لينكس: `fc-list`) وتظهر في خانة «خط المستند» ضمن مجموعة «خطوط ويندوز المثبّتة» — اختر أي خط وسيُطبَّق على المستند.
- على أوبنتو، الخطوط العربية الافتراضية قد تكون محدودة. ثبّت حزمة خطوط عربية مثل:
  ```bash
  sudo apt install fonts-noto-core fonts-hosny-amiri
  ```
  أو ارفع ملف خط عربي (TTF/OTF) من داخل البرنامج.
- الخطوط المرفوعة تُضمَّن تلقائيًا في ملف HTML المستقل عند التصدير.
- الحذف يعيد المستند إلى خط Cairo تلقائيًا إن كان الخط المحذوف مطبقًا.
