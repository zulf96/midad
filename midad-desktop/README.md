# مِداد ستوديو — نسخة سطح المكتب (ويندوز)

التطبيق نفسه (`midad-app.html`) يعمل الآن كبرنامج ويندوز حقيقي عبر **Electron**، دون أي تعديل على الكود الأصلي.

## الهيكل

```
midad-desktop/
├── app/
│   └── index.html      ← التطبيق (نسخة من midad-app.html — حدّثها بعد أي تعديل)
├── main.js             ← عملية الإلكترون: النافذة، القائمة، التنزيلات، حالة النافذة
├── preload.js          ← جسر آمن (contextIsolation)
├── package.json        ← الإعدادات وإعدادات المُثبِّت NSIS
└── build/              ← ضع هنا icon.ico (اختياري — يولَّد أيقونة افتراضية غيابه)
```

## التشغيل على ويندوز (للتطوير)

1. ثبّت **Node.js LTS** من https://nodejs.org (يكفي الإعداد الافتراضي).
2. من سطر الأوامر داخل مجلد `midad-desktop`:

```bat
npm install
npm start
```

## إنتاج المُثبِّت ‎.exe على ويندوز

```bat
npm run dist
```

الناتج في مجلد `release/`:
- `Midad Studio Setup 1.0.0.exe` — مُثبِّت كامل (اختيار مجلد التثبيت، اختصار سطح المكتب، قائمة ابدأ، بالعربية).

> ملاحظة: أول بناء يحتاج إنترنت لتنزيل Electron (~100MB)، وبنائه يأخذ دقائق.

## الحصول على ‎.exe بدون جهاز ويندوز (GitHub Actions)

1. ارفع المشروع إلى مستودع GitHub.
2. سير العمل `.github/workflows/build-windows.yml` يبني المُثبِّت تلقائيًا على كل دفعة.
3. حمّل الناتج من تبويب **Actions → Artifacts** (اسمه `midad-studio-windows`).

## ماذا يضيف الغلاف؟

- نافذة أصلية بحفظ أبعادها وموضعها بين الجلسات.
- قائمة عربية (ملف/تحرير/عرض/مساعدة) مع Ctrl+P للطباعة (يدعم الغلاف الداكن بـ `printBackground`).
- حفظ التصديرات (HTML/JSON) بمربع حوار «حفظ باسم» حقيقي.
- منع فتح تشغيل نسختين معًا.
- عزل أمني كامل (`contextIsolation` + `sandbox`، بدون Node داخل الصفحة).

## بيانات المستخدم

بيانات المحرر تُحفظ في تخزين التطبيق المحلي (نفس مفتاح `midad.studio.v1`) داخل
`%AppData%\midad-studio\Local Storage\` — تبقى بعد الإغلاق والتحديث.
(الترقية لاحقًا: نقل التخزين إلى ملف JSON مرئي للمستخدم لدعم النسخ الاحتياطي اليدوي.)

## تحديث التطبيق بعد تعديل midad-app.html

```bash
cp midad-app.html midad-desktop/app/index.html
```
